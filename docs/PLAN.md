## 2. 分工原則

1. **按子系統分工**：每人負責一半的系統，從需求一路做到設計，期末寫程式時沿用同樣的分法。
2. **一人寫、一人審**：每個 PR 由一人撰寫，另一人 approve，並在 PR 留下「簽核人：XXX」。這就是 Waterfall 的 human gate。
3. **AI 可以起草，只有人可以接受**：每次使用 AI 都要記在 `docs/ai-log/AI_LOG.md`。
4. **工時當天記**：寫在 `docs/TIMESHEET.md`，不要事後補。
5. **兩人都要能解釋全部內容**：作業規定任何組員都可能被抽問任何部分，所以審查時要真的讀懂對方的內容。
